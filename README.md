# Homenagem Antônio Marinho — 80 anos

Site estático com a letra da canção e player de áudio, para hospedar no GitHub Pages.

## URL do site

https://lucasfrotam.github.io/homenagem-antonio-marinho-80-anos/

## QR para impressão

Arquivos em `assets/`:

- `qr-site-impressao.png` — QR com fundo branco (melhor para imprimir)
- `qr-site.png` — QR com fundo transparente

O QR aponta para o link do site acima.

## Ativar GitHub Pages

1. Push deste repositório para o GitHub
2. Em **Settings → Pages → Build and deployment**
3. Source: **Deploy from a branch**
4. Branch: `main` / pasta `/ (root)`
5. Salvar e aguardar 1–2 minutos
